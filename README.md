# Vendor Risk Assessment – CloudDocs AI

## Overview
This project simulates a third-party vendor cybersecurity risk assessment from the perspective of a GRC Analyst.

The assessment evaluates CloudDocs AI, a fictional cloud-based document storage provider, to identify security and compliance risks related to handling sensitive business data.

## Frameworks Referenced
- NIST Cybersecurity Framework (CSF)
- ISO/IEC 27001
- SOC 2 Trust Services Criteria

## Project Deliverables
- Project Overview
- Vendor Security Questionnaire
- Cybersecurity Risk Register
- Vendor Risk Assessment Report
- Executive Summary
- Remediation Timeline

## Key Risks Identified
- Incomplete MFA enforcement
- Weak subcontractor oversight
- Lack of formal patch management timelines
- Limited suspicious login monitoring
- Absence of SOC 2 Type II certification
- Inadequate disaster recovery testing

## Skills Demonstrated

- Third-Party Vendor Risk Assessment
- Risk Identification and Analysis
- Control Mapping (NIST CSF, ISO 27001)
- Control Testing and Validation
- Policy Development (Access Control Policy)

## Tools Used

- Google Sheets / Excel
- Google Docs
- GitHub (Documentation & Version Control)

## Key Outcome

This project demonstrates the full GRC lifecycle from identifying risks to implementing and testing controls, and developing policies aligned with industry standards.
